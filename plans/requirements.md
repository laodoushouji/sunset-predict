# Sunset Predict — 完整需求文档

## 1. 产品定位
专业级晚霞/日出预测 Web 应用，对标 Alpenglow Pro，专注中国景区。
先做西湖一个景区，后续扩展黄山、故宫、青海湖等。

## 2. 技术架构
```
用户浏览器 (PWA)
    ↓ HTTP
Cloudflare Workers (TypeScript + Hono)
    ↓ API 调用
┌─ QWeather (和风天气) — 主数据源（逐小时预报）
├─ Open-Meteo GFS — 交叉验证源1
├─ Open-Meteo ECMWF — 交叉验证源2
└─ WAQI — 空气质量数据（PM2.5、臭氧）
```
- 前端：GitHub Pages，vanilla HTML/CSS/JS，PWA 离线可用
- 后端：Cloudflare Workers，免费额度 100k req/day
- 数据源策略：和风天气直接用，Open-Meteo 做交叉验证

## 3. 核心预测逻辑

### 3.1 通用5因子模型
所有景区共享的基础模型：

| 因子 | 权重 | 最优区间 | 逻辑 |
|------|------|---------|------|
| 高云量 (High Cloud, >6km) | 30% | 40-70% | 火烧云的画布，最先捕捉地平线下的阳光 |
| 中云量 (Mid Cloud, 2-6km) | 20% | 30-50% | 层次感来源，适中的中云产生色彩分层 |
| 低云量 (Low Cloud, <2km) | -25% | <20% | 晚霞杀手，遮挡阳光路径，重罚 |
| 能见度 (Visibility) | 15% | >15km | 影响色彩鲜艳度和饱和度 |
| 湿度 (Humidity) | 10% | 40-60% | 太干=薄雾少，太湿=雾气消光 |

公式：Quality = clamp(0, 100, 高云分×0.30 + 中云分×0.20 - 低云罚×0.25 + 能见度分×0.15 + 湿度分×0.10)

### 3.2 西方窗口检查（关键！）
不能只查头顶天气。太阳光从西方射来，需要检查日落方向 100-200km 外的云况。

**西湖的窗口点：**
- 点A（西湖）：30.25N, 120.15E → 高云 + 中云（决定有没有画布）
- 点B（临安）：30.24N, 119.72E（正西约43km）→ 低云 + 能见度（主窗口，权重60%）
- 点C（富阳）：30.05N, 119.95E（西南约18km）→ 低云（辅窗口，权重40%）

逻辑：
- 西方低云 < 10% + 能见度 > 15km → 乘数 +30-50%（光线畅通）
- 西方低云 > 40% → 乘数 -30-50%（光线被封死）
- 即使西湖头顶满天云，如果西方窗口被低云挡死，光线射不进来，分数照样低

### 3.3 景区专属修正插件
每个景区一个独立的修正模块，叠加在通用模型之上。

**西湖 V1 专属修正（6项）：**

| 修正项 | 影响 | 逻辑 |
|--------|------|------|
| 西北山脊遮挡 | ±7.5% | 宝石山/北高峰（200-400m）遮挡太阳高度角<2°时的最后5分钟直射光。但低云15-40%时反而有利（山脊部分阻挡低云帮助构图） |
| 水面反射 | +5-10% | 西湖水面 6.39km²，平静时反射天空色彩，等效增大可见天空面积。夏季+5%，冬季+10% |
| 临安窗口检查 | ±20% | 正西方约43km，主窗口 |
| 富阳窗口检查 | ±10% | 西南方约18km，辅窗口 |
| 高湿消光 | -5% | 杭州湿度普遍偏高，>80%时雾气削弱色彩饱和度，额外扣分 |
| 理想风速 | +5% | 3-8 m/s 最佳（吹散低云但保持高云），<1 m/s 扣3% |

**西湖计算流程：**
1. 获取西湖 (30.25, 120.15) 当日日落时间
2. 获取日落前1小时到日落+15分钟的气象数据
3. 运行通用5因子模型 → base_score
4. 叠加西湖6项专属修正 → corrected_score
5. 西方双窗口检查 → 乘数 + 额外罚分
6. 综合计算最终 quality 分数
7. 色彩倾向预测（含水面反射因素）
8. 最佳拍摄点推荐 + 反青光预测

### 3.4 色彩倾向预测
| 条件 | 色彩 | 说明 |
|------|------|------|
| 能见度>20km + AQI<50 | 通透金橙 | 空气极净，瑞利散射弱，金色直射为主 |
| 能见度>15km + 湿度>70% | 浪漫粉紫 | 高空湿度高，增强紫粉散射 |
| 湿度<40% + 能见度>10km | 干热深红 | 低湿大气，持续时间短 |
| AQI>150 | 灰蒙蒙 | 污染重，光线被吸收 |
| 湿度>85% | 银灰雾霭 | 雾化消光严重 |
| 其他 | 标准暖色 | 典型晚霞暖色调 |

### 3.5 反青光效应 (Alpenglow Effect)
太阳下山后，高云仍可被残余光照亮，产生蓝紫色反青光。
- 触发条件：高云量 > 70%
- 预测：太阳下山后仍有 10-15 分钟反青光时间
- 建议：适合长曝光拍摄

### 3.6 多源交叉验证
QWeather（主，权重50%）+ Open-Meteo GFS（权重25%）+ Open-Meteo ECMWF（权重25%）
- 三源一致（标准差<5）→ 置信度 high
- 有分歧（标准差<15）→ 置信度 medium，加权中值
- 大分歧（标准差≥15）→ 置信度 low

## 5. 后端 API

### 5.1 Cloudflare Worker 端点

```
GET /api/predict?lat=30.25&lon=120.15&event=sunset&date=2026-07-09
  - 查询任意坐标的晚霞/日出预测
  - event: sunset | sunrise
  - date: 可选，默认今天

GET /api/spot/xihu?event=sunset
  - 查询景区专属预测（调用该景区的插件算法）
  - 自动查西湖+临安+富阳三点数据

GET /api/forecast?lat=30.25&lon=120.15&days=3
  - 3天预报

GET /api/sun-times?lat=30.25&lon=120.15&date=2026-07-09
  - 日出日落时间计算
```

### 5.2 数据获取流程（以 /api/spot/xihu 为例）
1. 接收请求
2. 并行请求 3 个坐标的气象数据：
   - QWeather: 杭州 (101210101) — 主数据
   - QWeather 或 Open-Meteo: 临安 (30.24, 119.72) — 窗口检查
   - QWeather 或 Open-Meteo: 富阳 (30.05, 119.95) — 窗口检查
3. 同时请求 Open-Meteo GFS + ECMWF 做交叉验证
4. 运行通用5因子模型
5. 叠加西湖专属修正
6. 融合交叉验证结果，计算置信度
7. 色彩倾向 + 拍摄点推荐 + 反青光预测
8. 返回 JSON

产品页面需明确声明：
"晚霞预测基于气象模型数据计算，仅供参考。实际受微气候、突发天气等因素影响，可能与预测存在差异。"

## 10. 风险与应对
| 风险 | 应对 |
|------|------|
| QWeather 免费额度 1000次/天 | 缓存预测结果（同地点同日不重复请求） |
| Open-Meteo 在中国延迟 | QWeather 主数据源，Open-Meteo 只做验证，不影响主流程 |
| QWeather 24h接口无分层云量 | 临时用总云量经验比例估算，后续升级 Grid Weather 接口 |
| 预测准确率不高 | 公开声明仅供参考 + 用户反馈校准循环 |
| Cloudflare Workers 冷启动 | 免费额度足够个人项目，后续可升级 |
